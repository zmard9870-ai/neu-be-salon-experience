Use these as proposed website colours, not as confirmed official brand colours. Adapt them if the salon provides an existing logo or brand guidelines.

Typography:
- Use an elegant editorial-style heading font such as Cormorant Garamond or Playfair Display.
- Use a clean, highly readable sans-serif font such as Inter or Manrope for body text and buttons.
- Maintain excellent contrast and readable text sizes.

Design principles:
- Premium editorial layout.
- Generous whitespace.
- Large, high-quality salon photographs.
- Refined rounded corners, subtle borders, and restrained shadows.
- Elegant gold accents rather than excessive metallic effects.
- Consistent spacing and alignment.
- Smooth, subtle transitions.
- Avoid clutter, excessive gradients, cartoon illustrations, and cheap-looking effects.

The website should feel luxurious but approachable, suitable for a neighbourhood salon serving both men and women.

## 18. TECHNICAL REQUIREMENTS

Preferred implementation:
- React with Next.js and TypeScript.
- Tailwind CSS or an equivalent consistent styling system.
- Reusable components.
- Lucide icons.
- Responsive, mobile-first layouts.
- Optimised WebP or AVIF imagery.
- Semantic HTML.
- Accessible forms and navigation.

If the platform uses another framework, adapt the implementation without sacrificing performance or functionality.

Performance:
- Aim for a Lighthouse performance score of 90+ where feasible.
- Optimise image dimensions and file sizes.
- Lazy-load below-the-fold images.
- Avoid unnecessary JavaScript and heavy animations.
- Prevent layout shifts.
- Use font loading strategies that minimise flashes of unstyled text.

Accessibility:
- Target WCAG 2.2 AA where feasible.
- Ensure keyboard navigation.
- Use visible focus indicators.
- Maintain sufficient colour contrast.
- Label all form fields.
- Respect reduced-motion preferences.
- Provide useful alt text.

Security:
- Validate all form submissions on the server.
- Use HTTPS in production.
- Protect API keys and secrets.
- Add spam protection where appropriate.
- Do not collect unnecessary personal data.
